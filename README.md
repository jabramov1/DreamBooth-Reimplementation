# DreamBooth Reimplementation and Experimental Extensions

This repository contains our reimplementation and experimental exploration of DreamBooth for subject-driven text-to-image generation using Stable Diffusion 1.5 as the base model. Our goal was to understand the main DreamBooth training setup, reproduce its behavior on several subjects, and test how different training choices affected the generated images.

We implemented the training loop, inference pipeline, and evaluation metrics around Stable Diffusion 1.5. We first reproduced the paper's core results, including subject and prompt fidelity, prior preservation, and the ability to generate a learned subject in new prompts and settings.

We then extended the project with experiments designed to explore DreamBooth's behavior and limitations. These included assigning multiple subjects to the same identifier token, combining a learned subject with other species through prompting, and applying DreamBooth to a human subject. We also tested how choices such as learning rate, number of training images, and text-encoder fine-tuning affected the results.

## Reproduced Results and Benchmarks

Our reimplementation focused on three core DreamBooth results:

- **Subject-driven generation:** Fine-tuned Stable Diffusion 1.5 on a small set of reference images using a rare identifier token, then tested whether the subject remained recognizable in new scenes and prompts.
- **Quantitative evaluation:** Measured subject fidelity with DINO and CLIP-I and prompt fidelity with CLIP-T, comparing our results against the Stable Diffusion results reported in the original paper.
- **Prior preservation:** Trained models with and without prior-preservation loss to test whether removing it caused the generic class to collapse toward the learned subject.

## Experimental Extensions

We also designed experiments to test DreamBooth beyond the standard setup:

- **Multiple subjects under one token:** Trained two dog breeds with the same identifier token; generated images blended traits from both subjects.
- **Cross-species prompting:** Combined a learned subject with other concepts, such as a dog-panda hybrid, to examine how the learned identity interacted with the base model's existing knowledge.
- **Human personalization:** Fine-tuned on a human subject and generated the person in new roles and settings, with recognizable but less consistent identity preservation than for some animal and object subjects.
- **Training ablations:** Varied U-Net learning rate, number of reference images, prior preservation, and whether the CLIP text encoder was frozen or fine-tuned.

## Implementation

Images were resized to 512 × 512 and encoded into latent space with the VAE, while CLIP encoded the text prompts. For the main experiments, the VAE and text encoder were frozen and the U-Net was fine-tuned using the DreamBooth noise-prediction objective. Prior-preservation runs additionally trained on generic class images generated by the frozen base model.

## Experiments

We ran several types of experiments:

1. **Subject generation**
   - Trained DreamBooth models on different subjects and evaluated whether subject identity was preserved across new prompts and scenes.

2. **Learning rate comparisons**
   - Tested different learning rates to compare training stability, subject fidelity, and output quality.

3. **Prior preservation comparisons**
   - Compared models trained with and without prior preservation to measure class collapse and subject fidelity.

4. **Prompt variation experiments**
   - Tested richer and more varied prompts to evaluate how well the fine-tuned model generalized beyond training-like prompts.

5. **Multi-subject and custom-subject experiments**
   - Tested multiple subject categories, including animals, toys, household objects, and custom subjects, and explored binding multiple subjects to the same identifier token.

The project includes several notebooks to support multiple experiments running in parallel. Different notebooks correspond to different subject sets, prompt styles, learning rates, and ablation experiments. Some focus on specific subjects such as Killian, while others compare training settings or test object generation across dogs, cats, clocks, backpacks, robot toys, plushies, sneakers, and teapots.

The main results are organized in the `Results/` folder. Each experiment has its own folder, with subfolders for each subject or object. For example:

```text
Results/experiment_name/object_name/
```

Inside each object folder, the main output is usually `grid.png`, which shows the final generated images for that subject. Other useful files include:

```text
loss_curve.png
prior_vs_no_prior.png
preview_step_400.png
drift_step_400.png
metrics_table.png
all_metrics.csv
```

These files help compare training behavior, prompt performance, prior-preservation effects, and output quality across experiments.

## Repository Structure

- `dreambooth_dataset/`
  - Contains the subject images used for training, including standard/object-style subjects and custom subjects used in our experiments.

- `Results/`
  - Contains generated outputs, image grids, loss curves, prior-vs-no-prior comparisons, intermediate previews, and metrics for each experiment.

- `*.ipynb`
  - Colab notebooks used for different experiment groups, including learning-rate comparisons, object generation, dog-breed mixing, and rich prompt generation.

## How to View Results

To inspect the results, open the `Results/` folder, choose an experiment, and then select the corresponding subject or object folder.

For example:

```text
Results/dog2_cat2_clock_lr5/dog2/grid.png
```

`grid.png` shows the generated outputs for that subject. Files such as `prior_vs_no_prior.png`, `loss_curve.png`, and `metrics_table.png` provide comparisons and training diagnostics.
